## Current checkpoint

All shipping platforms now use the same root and native store. Bootstrap selects the recoverable legacy handoff or a durable fresh installation before exposing services. It preserves the old files and never opens the retired writer after activation or logout. Preparation coalesces across cancelled/remaining waiters, with explicit failure and retry. The native assembly receives exactly that open store; fixture selection happens once at the application boundary.

The scene-keyed SwiftUI startup task fixes a missed automatic-sync start when activation precedes bootstrap completion. Saved Work observes committed store changes, so automatic uploads update its count. Japanese input uses one narrow UIKit bridge on iOS and the native SwiftUI field on Mac; deferred responder changes avoid the hosting-graph recursion found during testing. Native main settings retain the original minute/keyboard controls. Background work uses SwiftUI's built-in app-refresh scene API and explicit shared synchronization. Original lesson/review search and Siri activity identities share one metadata implementation and are donated with SwiftUI userActivity; the old UIKit adapter is explicitly MainActor-isolated.

Shared suites pass 478 functions on Mac and iOS, hosted integration passes 107, and all nine native UI cases have passing evidence on each mobile device. Thirteen separate-process storage/handoff/native-selection phases pass, including expected abrupt exits. Mac/iOS Release, native Mac test compilation and retained watch builds pass. Mac GUI execution, signed upgrades and real system delivery are not claimed. Exact runs, earlier failures, source/LOC scopes and remaining gates are in [native cutover validation](Validation/2026-10-20-native-ios-cutover.json).

Fifty-four runtime JSON files are required Apple asset/icon metadata; there are no standalone SQL data resources. Four old adapters still contain SQL: the read-only importer and the old cache/sync/outbox used by the legacy test host. Shared storage uses SwiftData. API JSON and isolated response fixtures remain contracts.
